# freeCodeCamp Contributors Guide & Recognition

Thank you for your interest in contributing to freeCodeCamp! This project thrives because of thousands of volunteers around the world who contribute code, curriculum challenges, documentation, and translations.

## Getting Started

If you are new to freeCodeCamp open source:

1. **Read the Documentation**: Visit the comprehensive contributor documentation at [https://contribute.freecodecamp.org](https://contribute.freecodecamp.org).
2. **Find an Issue**: Browse open issues tagged with [`help wanted`](https://github.com/freeCodeCamp/freeCodeCamp/labels/help%20wanted) or [`first-timers-only`](https://github.com/freeCodeCamp/freeCodeCamp/labels/first-timers-only).
3. **Follow the Git Workflow**:
   - Fork the repository to your own GitHub account (`https://github.com/your-username/freeCodeCamp`).
   - Clone your fork locally: `git clone https://github.com/your-username/freeCodeCamp.git`
   - Create a feature branch: `git checkout -b feature/your-feature-name`
   - Make your changes following the style guide and testing guidelines.
   - Commit changes with conventional commit messages: `git commit -m "docs: improve contributor guide"`
   - Push to your fork: `git push origin feature/your-feature-name`
   - Open a Pull Request against the `main` branch of `freeCodeCamp/freeCodeCamp`.

## Types of Contributions

* **Curriculum**: Fix typos, add explanations, or write new interactive coding challenges.
* **Documentation**: Improve guides, setup instructions, and community policies.
* **Platform Code**: Enhance the web application, APIs, and client-side tooling.
* **Translations (i18n)**: Help localize challenges into Spanish, Chinese, Portuguese, and more.

## Recognition

Every contribution counts! All contributors are acknowledged in the official freeCodeCamp community platforms and git commit history.

For community discussions and real-time help, join our [Discord Server](https://discord.gg/PRyKn3Vbay) or post on our [Community Forum](https://forum.freecodecamp.org).
